ドノヘン？ — 厳選100種類・途中退出／リロード復帰対応版

【今回の更新】
元の200種類から100種類を厳選。src/prompts.ts と お題一覧_100種類.md は同じ内容・順番です。5戦内の重複防止と既存機能は維持しています。

【更新方法】
1. ZIPを新しいフォルダーに展開します。
2. 以前の .env.local をコピーします（キーは公開・共有しないでください）。
3. npm.cmd install を実行します。
4. npm.cmd run build でビルド、npm.cmd run dev でローカル起動できます。
5. 途中退出・復帰版のSQLが既に適用済みならSQLの再実行は不要です。それより古い版または新規環境では、supabase/schema.sql の全文をSupabase SQL Editorで実行してください。
6. 全参加者が更新後の画面を読み込み、新しいルームで開始してください。既存ルームの現在のお題・履歴は書き換えません。
7. 公開先では更新したソースから再ビルド・再デプロイします。環境変数は既存の設定を引き継ぎます。

【確認する操作】
・2人以上で作成／参加 → ホストが開始 → ヒント → 各自予想 → ホストが公開。
・5戦のお題が重複せず、5戦後にランキングが表示される。
・同じブラウザーでリロードし、同じID・得点・回答状態で復帰する。
・ホスト退出で権限が移動する。ヒント役退出では同一ラウンドをやり直す。
・残り1人では待機部屋へ戻り、再開すると5戦を最初から始める。

詳しい仕様とセットアップは README.md を参照してください。
